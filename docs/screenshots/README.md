# 📸 Screenshots

Folder ini menyimpan screenshot halaman website yang direferensikan di `README.md`.

## Cara menambah screenshot

1. Jalankan dev server: `npm run dev` (atau buka versi live).
2. Buka halaman yang ingin di-screenshot, mis. `http://localhost:5173/layanan`.
3. Ambil **full-page screenshot**:
   - **Chrome DevTools** → `Ctrl+Shift+P` → ketik `screenshot` → pilih *Capture full size screenshot*.
   - atau pakai ekstensi full-page screenshot.
4. Simpan dengan nama sesuai halaman, contoh:

| File | Halaman |
|------|---------|
| `layanan.png` | `/layanan` |
| `layanan-bot.png` | `/layanan/bot` |
| `tentang.png` | `/tentang` |
| `proyek.png` | `/proyek` |
| `harga.png` | `/harga` |
| `faq.png` | `/faq` |

Screenshot yang belum ada akan tampil sebagai gambar kosong di README sampai diisi.
